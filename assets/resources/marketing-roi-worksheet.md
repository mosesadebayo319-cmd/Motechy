## 3. Enter the amounts and calculate

| Input or result                                   | Your amount in naira | Calculation / definition                                        |
| ------------------------------------------------- | -------------------- | --------------------------------------------------------------- |
| A. Attributed net sales                           |                      | Completed paid orders, after discounts/refunds                  |
| B. Variable fulfilment costs                      |                      | Actual costs for the associated orders                          |
| C. Contribution                                   |                      | A minus B                                                       |
| D. Media ad spend                                 |                      | Ad charges only                                                 |
| E. Other marketing costs                          |                      | Content, management, staff allocation, tools and relevant fees  |
| F. Total marketing costs                          |                      | D plus E; no double counting                                    |
| G. Contribution after marketing                   |                      | C minus F; before remaining overhead/tax                        |
| H. Estimated contribution-based marketing ROI (%) |                      | G divided by F, multiplied by 100; F must be positive           |
| I. Revenue ROAS (multiple)                        |                      | Sales credited to the paid ads divided by D; D must be positive |
| J. Contribution margin ratio                      |                      | C divided by A; use only with positive sales                    |
| K. Revenue to cover marketing costs               |                      | F divided by J; only with positive, stable J and fixed F        |

Use the actual naira charge for foreign-currency bills and record the billing
date and transaction fees. Separate any estimated unpaid owner time from cash
costs. Do not count agency-inclusive media costs a second time.

K is not whole-business break-even. Recalculate for changing product mix,
fulfilment costs or marketing investment. Revenue ROAS is not applicable with
zero ad spend; ROI is undefined if its denominator is zero or unknown.

## 4. Check against an illustrative example

Hypothetical Enugu office-catering campaign, with all sales below attributed to
the paid campaign under its stated rule. Amounts are teaching assumptions only.

- A: ₦600,000 net sales.
- B: ₦360,000 variable fulfilment costs.
- C: ₦240,000 contribution.
- D: ₦100,000 media ad spend.
- E: ₦30,000 content plus ₦50,000 management/staff = ₦80,000.
- F: ₦180,000 total marketing costs.
- G: ₦60,000 contribution after marketing, before remaining overhead/tax.
- H: 60,000 / 180,000 × 100 = 33.3% (rounded).
- I: 600,000 / 100,000 = 6× revenue ROAS.
- J: 240,000 / 600,000 = 0.40 (40%).
- K: 180,000 / 0.40 = ₦450,000 to cover marketing costs only.
- Equivalent ROAS at K: 450,000 / 100,000 = 4.5× for these assumptions only.

Attribution is not proof that every sale was caused by the campaign. Sensitivity
example: assume only 75% of sales are incremental and variable costs scale
proportionally. Then ₦450,000 sales minus ₦270,000 variable costs minus ₦180,000
marketing leaves ₦0 (0% incremental ROI). The 75% is not a measured estimate.
